# 08 — cmd/kairos：GUI

**What to build:** Fyne 桌面界面，组装 01-07 全部包——输入文件选择（拖拽 + Fyne 内置 `dialog` 系统对话框）、输出目录选择（`dialog.ShowFolderOpen`，默认预填源文件同目录）、处理进度展示、完成后自动预览、历史记录列表、首次运行 DeepSeek API Key 引导。

**Blocked by:** 01, 02, 03, 04, 05, 06, 07

**Status:** ready-for-agent

- [ ] 从选文件到拿到高光片段的完整用户操作流程可用，不需要命令行
- [ ] 输出目录一旦确定（接受默认或改完）自动开始处理，没有独立"开始"按钮
- [ ] 处理进度分阶段展示：音轨提取中→识别台词中→判定高光中→剪辑中
- [ ] 处理完成自动弹出预览窗口播放高光片段
- [ ] 首次运行引导用户输入 DeepSeek API Key，存本地配置文件
- [ ] 历史列表能查看过往记录的转写文本和判定理由
- [ ] 源文件处理中被删除/移动、磁盘空间不足、CUDA 不可用、LLM 超时或 API Key 无效——均有明确错误提示，不崩溃

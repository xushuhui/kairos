# 06 — 真实素材端到端验证（第一版 demo 里程碑）

**What to build:** 把 02（video）/03（asr）/04（llm）的真实实现接入 05 的编排逻辑（替换 mock），做一个最小命令行入口（不需要 GUI），对 1 条真实短剧素材跑通完整链路：本地文件 → 提取音轨 → 本地 Paraformer 转写（CUDA）→ DeepSeek 判定 → 窗口计算 → FFmpeg 剪辑（NVENC）→ 输出可播放片段。

**Blocked by:** 02, 03, 04, 05

**Status:** ready-for-agent

- [ ] 给定一个真实短剧 MP4（1-3 分钟），命令行运行端到端不崩溃
- [ ] 产出可播放的高光片段文件，时长落在 45-75 秒区间
- [ ] 人工核对：转写文本基本准确，没有明显影响理解的错字/漏字
- [ ] 人工核对：LLM 的判定理由讲得通，`narrative_structure` 四阶段划分跟真实剧情大致对得上
- [ ] 人工核对：片段内容确实适合做广告钩子——路人观众（零上下文）能看懂冲击点在哪、片段制造了悬念/信息缺口，不是单纯"剧情最重要"但需要前情提要才看得懂的一段
- [ ] 人工核对：片段结尾落在情绪/冲突高点附近（悬念式收尾），不是卡在台词中间
- [ ] 如果验证发现明显漏判（比如漏掉一个台词稀疏但更精彩的沉默画面时刻），记录下来作为触发引入视觉理解模型的证据（见 map.md Out of Scope）
